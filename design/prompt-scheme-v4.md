# v4 方案示例

正式格式、抽樣與歷史行為見 [STYLE-JSON.md](../STYLE-JSON.md)。

本目錄的 `prompt-scheme-v4.example.json` 和 `style-library-v4.example.json` 是相互搭配的自訂主題和畫風庫示例，可修改 library ID 後一起匯入；它們是示例資料，與 App 內置畫風庫同名，匯入時請先改成另一個庫 ID 並同步修改主題的 `style.recommended`。

實際內置的四個遷移主題位於 `src/v4/themes/`，五種內置畫風在 `src/v4/default-styles.json`。首頁、主題管理頁和托盤出圖均使用 v4。內置主題在轉換時保留原有的主題及畫風變量與標籤條件；舊畫風中可能覆蓋主題場景的背景選項，改為不指定場景的背景層次描述。

每個方案的 `candidate_count` 是合法候選的抽樣目標；生成器最多嘗試 20,000 次，不會因搜尋次數耗盡而斷言方案必定無解。選項權重僅在候選提出時使用一次，偏好與避重只在合法候選評分時使用。可選項若自身約束不成立會被省略。詳細限制與本地歷史策略見正式格式文檔。
