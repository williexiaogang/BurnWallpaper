# 燃 BURN —— Windows 动漫壁纸应用 完整规格

> 版本：v1.1　｜　日期：2026-11-15　｜　平台：Windows 10 / 11  
> 本文档合并功能需求与完整 UI 设计规范，供 coding agent 直接使用。

## 0. 产品定位

| 项目 | 内容 |
|---|---|
| 产品名 | 燃（英文 BURN） |
| 一句话 | 给你的桌面换上热血二次元壁纸 |
| 内容风格 | 二次元、成年男性角色、肌肉力量感、运动热血、战斗 |
| 核心价值 | **壁纸本身**，以及"它挂在我桌面上好不好看" |
| AI 的角色 | 只是后台工具。**界面中不出现** "AI""生成""模型""提示词"等字样 |
| 出图方式 | 用户自备 API Key（RunComfy），在设置中配置 |
| 开机行为 | 支持开机自动出一张新壁纸并上墙（可关闭） |

## 1. 设计理念与原则

### 1.1 核心理念：少年漫画分镜

整个界面像一页漫画：**壁纸是主画面，UI 是贴在画面上的分镜框、招式名和拟声字**。

### 1.2 五条原则

1. **壁纸占 90%**：壁纸全屏铺满窗口，UI 只是浮在上面的一层，不使用侧边栏，也不用卡片容器。
2. **一个强调色**：全局只有爆燃橙一种强调色，其余全是黑白灰。
3. **斜切代替圆角**：所有容器、按钮、标签、缩略图都用斜切边，**全局零圆角**。
4. **快、狠、短**：动效时长不超过 450ms，强调冲击感，不做柔和飘浮。
5. **生成要隐形**：用户的感受是"在一个无限的壁纸库里挑图"，而不是"在操作 AI"。

## 2. 视觉规范

### 2.1 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `--ink` | `#0D0D0D` | 主背景、深色文字 |
| `--ink-2` | `#1A1A1A` | 次级背景（设置页、弹层） |
| `--paper` | `#F2EFE9` | 主文字、浅色按钮、标签底 |
| `--paper-dim` | `rgba(242,239,233,.5)` | 次要文字、描边数字 |
| `--blaze` | `#FF4D1A` | **唯一强调色**：主按钮、选中态、Logo、招式名阴影 |
| `--blaze-deep` | `#C2340E` | 强调色按下态 |
| `--ok` | `#3DDC84` | 仅用于 API 连接状态指示点 |
| `--err` | `#FF2E4D` | 仅用于错误状态指示点 |

**规则**
- 爆燃橙同一屏最多出现 **3 处**。
- 禁止使用渐变色按钮；壁纸上的遮罩渐变只允许黑色到透明。
- 壁纸遮罩：
  - 左侧：`linear-gradient(90deg, rgba(0,0,0,.7) 0, rgba(0,0,0,.15) 55%, transparent)`
  - 底部：`linear-gradient(0deg, rgba(0,0,0,.85), transparent)`，高度 120px

### 2.2 字体

| 用途 | 字体 | 授权 | 字号示例 |
|---|---|---|---|
| 中文标题（招式名） | 站酷庆科黄油体 ZCOOL QingKe HuangYou | 免费商用 | 64–96px |
| 英文 / 数字 | Anton | OFL | 期号 120px 描边，副标题 13px |
| 中文正文 / UI | HarmonyOS Sans SC（备选 Noto Sans SC） | 免费商用 / OFL | 12–14px |
| 等宽数据 | JetBrains Mono | OFL | 10–11px |

**排版规则**
- 期号：Anton，空心描边 `-webkit-text-stroke: 1.5px var(--paper-dim)`，与下方招式名重叠约 30%。
- 招式名：黄油体，带硬投影 `text-shadow: 4px 4px 0 var(--blaze)`，不带模糊。
- 英文副标题：Anton，字间距 `.35em`，颜色为爆燃橙。
- UI 正文字重只用 500 和 900 两档。

### 2.3 形状：斜切系统

所有组件的斜切角度统一为 **约 12°**。

```css
/* 小号：标签、Chip */
--cut-s: polygon(6px 0, 100% 0, calc(100% - 6px) 100%, 0 100%);
/* 中号：按钮 */
--cut-m: polygon(8px 0, 100% 0, calc(100% - 8px) 100%, 0 100%);
/* 大号：缩略图、输入框 */
--cut-l: polygon(14px 0, 100% 0, calc(100% - 14px) 100%, 0 100%);
/* Logo 块：右侧单边斜切 */
--cut-logo: polygon(0 0, 100% 0, 82% 100%, 0 100%);
```

- 相邻的缩略图使用负间距 `margin-right: -10px`，让斜边彼此咬合。
- `border-radius` 全局为 0（唯一例外：Windows 系统窗口圆角由系统处理）。

### 2.4 间距与栅格

- 基础单位：**4px**
- 常用间距：4 / 8 / 12 / 16 / 22 / 32 / 48
- 页面安全边距：左右各 22px
- 底部壁纸架高度：84px
- 顶栏高度：42px

### 2.5 图标

- 线性图标，线宽 2px，端点为直角（`stroke-linecap: square`）
- 推荐 Lucide 或 Tabler，**禁止使用星星、魔法棒、闪光这类图标**
- 尺寸：16 / 20px

### 2.6 质感

- 半调网点（Halftone）：只作为装饰，用在空状态和设置页背景上，透明度 ≤ 0.35
- 速度线：只在空状态插画和加载状态中使用
- 不使用毛玻璃（例外是模拟 Windows 任务栏的预览层）

### 3.1 顶栏 TopBar

```

### 3.2 作品标签 TitleBlock（左上信息区）

```

破拳            ← 黄油体 68px + 橙色硬投影（与期号重叠）

### 3.3 按钮 Button

| 类型 | 背景 | 文字 | 用途 |
|---|---|---|---|
| Primary | `--blaze` | `--ink` | 上墙（每屏只出现一个） |
| Secondary | `rgba(0,0,0,.55)` | `--paper` | 桌面预览、收藏 |

### 3.4 描述输入框 AskBar

- GO 按钮：黑底，橙色 Anton 字体
- 快捷标签（Chip）：1px 描边，选中后描边和文字都变为橙色，可以多选

### 3.5 壁纸架 Shelf（底部缩略图）

- 左侧放竖排小标题 `RECENT`（Anton，橙色）

### 3.6 显示器选择器 MonitorPicker

- 按真实的屏幕排列、比例和横竖方向绘制小矩形

- 多屏时提供开关：「每屏一张」或「跨屏连续」

### 3.7 提示 Toast

- 位置：右上角，距顶栏 12px
- 样式：黄油体 22px，橙色字，黑色硬投影，倾斜 `skewX(-10deg)`
- 动画：从右侧滑入 20px，停留 1.4 秒，然后淡出
- 示例文案：「已上墙！」「收进收藏」

## 4. 页面规范

默认窗口 1280×800，最小 960×600。

### 4.1 此刻（首页）

壁纸全屏铺满，UI 浮层覆盖。
- 左上：作品标签
- 左下：描述输入框
- 右下：显示器选择器、桌面预览、上墙
- 底部：壁纸架
- 交互：
  - `←` / `→` 切换壁纸
  - 鼠标闲置 3 秒后，UI 淡出到透明度 0.15，只留下壁纸；移动鼠标后恢复

### 4.2 桌面预览与裁切

- 进入预览后，所有 UI 淡出，叠加一层模拟 Windows 桌面：
  - 桌面图标：读取用户真实的图标数量和排列方向
  - 任务栏：读取系统设置（居中/左对齐、高度）
- 右上角只保留「退出预览」，`Esc` 也可以退出
- **裁切模式**：按住画面拖动，调整取景位置，让人物避开图标区域
  - 可选开关：显示三分线
  - 底部浮出「确认并上墙」

### 4.3 收藏

- 布局：杂志式不规则网格，壁纸按真实比例混排（16:9、21:9、32:9、竖屏）
- 顶部筛选：题材、色调、明暗
- 悬停时显示招式名与操作
- 右键菜单：上墙、设为某屏、导出原图、复制描述、再来一张类似的

### 4.4 轮换

- 主体是一条横向的 **24 小时时间轴**
- 把壁纸从收藏拖到时间轴上，形成时段块
- 规则选项：固定时段、每 N 分钟随机、每天自动出一张新的
- 预设方案：「早燃晚静」

### 4.5 设置

背景用 `--ink-2`，配半调网点装饰。分组标题用 Anton 橙色大写。

| 分组 | 项目 |
|---|---|
| **SOURCE 图源** | 服务商选择（默认 RunComfy）、API Key（默认打码）、连接状态、本月用量、测试连接 |
| **STYLE 画风** | 默认画风、角色体型偏好、默认构图 |
| **DISPLAY 显示** | 多显示器策略、分辨率、自动放大 |
| **SYSTEM 系统** | 开机启动、关闭窗口后最小化到托盘、存储位置、缓存清理 |
| **ABOUT 关于** | 版本、更新检查 |

### 4.6 首次启动引导（3 步）

1. 「欢迎来到燃」：全屏轮播示例壁纸
2. 「接上图源」：填入 API Key 并测试连接
3. 「选你的热血」：多选题材标签作为默认偏好

### 4.7 系统托盘菜单

```

──────────
再来一张        Ctrl+Alt+N
下一张          Ctrl+Alt+→
收藏当前        Ctrl+Alt+S
──────────
暂停轮换
打开燃
退出

## 5. 动效规范

| 场景 | 动效 | 时长 | 缓动 |
|---|---|---|---|
| 切换壁纸 | 橙色斜条从左向右斩过画面，在中点替换壁纸 | 450ms | `cubic-bezier(.7,0,.3,1)` |
| 上墙 | 窗口震动（±3px） + Toast 弹出 | 220ms + 1400ms | `linear` / `ease-out` |
| 出图中 | 缩略图闪烁 | 每周期 500ms | `steps(2)` |
| 出图完成 | 自动切换到新图（使用斩击转场） | 450ms | 同上 |
| 页面切换 | 内容整体向左平移 24px 并淡入 | 200ms | `ease-out` |
| 按钮悬停 | 向右位移 2px，亮度提高 | 120ms | `ease-out` |
| UI 闲置淡出 | 透明度从 1 到 0.15 | 600ms | `ease` |
| 进入桌面预览 | UI 淡出，桌面层淡入 | 300ms | `ease` |

**规则**：禁止弹跳、弹簧、持续循环装饰动画。跟随 Windows「动画效果」开关。

## 6. 文案规范

### 6.1 语气
短、直接、有劲，像漫画里的台词。不卖萌，也不写技术术语。

### 6.2 用词对照

| 不要写 | 改写为 |
|---|---|
| AI 生成 / 生成图片 | 来一张 / 下一张 |
| 输入提示词 | 下一张想看什么？ |
| 正在生成… | （不显示文字，只用缩略图闪烁表示） |
| 设为壁纸 | 上墙 |
| 已设置为壁纸 | 已上墙！ |
| 添加到收藏 | 收了 |
| 删除 | 丢掉 |

### 6.3 错误提示

| 场景 | 标题 | 说明 |
|---|---|---|
| Key 无效 | 图源断了 | API Key 无效或已过期，去设置里换一个 |
| 额度用完 | 弹药耗尽 | 本月额度已用完，可以先从收藏里挑 |
| 网络失败 | 连不上 | 检查网络后再试一次 |
| 内容被拒绝 | 这张没出来 | 换个描述试试 |
| 设置壁纸失败 | 没挂上 | 系统拒绝了这次修改，请重试 |

## 7. 壁纸生成策略（后台，用户不可见）

### 7.1 提示词拼装

```
[画风锁定] + [角色基础] + [用户描述] + [快捷标签映射] + [构图指令] + [质量词]
```

| 片段 | 示例内容 |
|---|---|
| 画风锁定 | `anime coloring, thick painting, high contrast, dramatic lighting` |
| 角色基础 | `1boy, solo, adult male, muscular male` + 体型偏好 |
| 标签映射 | 拳击 → `boxer, boxing gloves, boxing ring`；雨夜 → `heavy rain, night, neon reflections` |
| 构图指令 | `off-center composition, rule of thirds, character on right side, empty space on left, wide shot` |
| 质量词 | `masterpiece, best quality, absurdres` |
| 负面词 | `text, logo, watermark, team name, jersey number, 1girl, bad anatomy, bad hands, lowres` |

> 负面词里必须包含 `team name, jersey number, logo`，避免版权风险。

### 7.2 构图保障

1. 用更宽的画幅出图（例如 21:9），再按屏幕比例裁切
2. 对出好的图做主体检测，自动把人物裁到桌面图标的另一侧
3. 用户可在桌面预览中手动微调取景

### 7.3 分辨率

- 自动读取每台显示器的物理分辨率和缩放比例
- 先按模型支持的最大尺寸出图，再放大到屏幕原生分辨率
- 原图和放大后的图都保存

### 7.4 自动命名

维护“招式名”词库，按题材分组。每条包含中文两字名和英文名，例如：
- 拳击：破拳 KNOCKOUT · 重锤 HAMMER
- 战斗：焚城 WILDFIRE · 怒涛 TIDAL RAGE
- 球类：扣杀 SLAM DUNK · 冲锋 CHARGE
- 格斗：雨蹴 RAIN KICK · 烈风 GALE

根据用户选的标签抽取名字，不重复使用，用完后自动加罗马数字后缀。期号全局递增。

## 8. RunComfy 集成与开机行为

### 8.1 认证与调用

- Base URL：`https://model-api.runcomfy.net/v1`
- Header：`Authorization: Bearer <API_KEY>`
- 推荐默认模型：`blackforestlabs/flux-2/turbo/text-to-image`
- 异步流程：提交 → 获取 request_id → 轮询 status → 获取结果 URL → 下载到本地 → 上墙

### 8.2 开机自动出图

- 设置中可开关「开机启动」与「开机自动来一张」
- 启动后延迟 10–30 秒（或检测网络就绪）再执行
- 失败时保留上一张壁纸，不强制覆盖

### 8.3 配置与安全

- API Key 存入 Windows Credential Manager，禁止明文
- 本地数据使用 SQLite（壁纸元数据、收藏、轮换规则、招式名使用记录）
- 图片三级缓存：原图 / 放大图 / 缩略图（WebP）

## 9. 状态设计

| 状态 | 表现 |

| 空状态 | 黑底 + 速度线 + 「还没开打」+ 描述输入框 |

| 离线 | 顶栏小灰点，输入框置灰 |
| 未配置 Key | 输入框置灰，提示「先接上图源」 |

## 12. 禁止清单

- 紫蓝渐变、霓虹 RGB 渐变
- 星星、魔法棒、闪光图标
- 任何"AI""生成""模型""提示词"字样
- 大面积毛玻璃卡片
- 圆角按钮、胶囊形状
- 正中央一个大输入框的布局
- 转圈加载动画、百分比进度条
- 弹跳和弹簧动效
- 同一屏中出现多种强调色
- 默认的系统字体（标题必须使用指定字体）

3. 设置页（图源、开机启动）
4. 收藏与轮换
5. 桌面预览与裁切
6. 首次引导与托盘

请优先保证视觉规范（斜切、爆燃橙、壁纸占 90%）和文案规范被严格执行。
