## 三层解耦改造：JSON 成为唯一风格入口（同日晚）

用户明确最终目标：**只用 JSON 就能制作各种风格的图片，代码可以为这个目标更新**。据此完成 JSON 大改造 + 代码通用能力增强。

### 诊断结论
锁死「一个角色只能一个风格」的不是 ANIMAL，而是三处：模板首句硬编码 `muscular anthropomorphic` + `cinematic/poster`；内容变量池全肌肉/全热血/全健身；ART_STYLE 每个只提供 1 个 tag 且 RENDERING `requires.every` 导致画风一选渲染池只剩 1–2 项。确认 UI 无变量名硬编码、内置预设每次从 JSON 读取（`data.ts` import）。

### 代码层（通用能力，全部可选字段、无硬编码）
- `types.ts`：`StyleOption.any_of` / `excludes` / `weight`，`StyleVariable.group`（content/style/presentation），`PresetTest.expect` 新增 `values` / `prompt_contains` / `prompt_excludes` / `group_excludes`，新增 `compare`。
- `utils/prompt.ts`：`compatibleOptions` 支持新约束、`pickValue` 支持权重（无权重时保持原随机逻辑，零回归）、`runPresetTests` 支持全部新断言与 compare。
- `utils/preset-json.ts`：导入校验同步新字段；AI 指令与 preset 示例更新分层规则。
- `AskBar.tsx`（optgroup）/ `StylesPage.tsx`（三组分节）/ `styles.css`：UI 按 JSON 的 `group` 分层渲染，新增 `.variable-layer` 样式。

### JSON 层（general 预设）
26 变量（content 13 / style 7 / presentation 6）、22 段模板、10 条 tests。首句去硬编码；`BODY_FEATURE→BODY_BUILD`、`FUR_DETAIL→COAT_PATTERN`、`BACKGROUND→SCENE + BACKDROP`、`RENDERING→MATERIAL/BRUSH/FINISH`；画风 9→16 种且多标签；补萌系体型/表情/情绪/道具；去 `his` 与材质词；TEXT 按画风族约束。

## .sample 增量工作流与 git 忽略名单维护（同日，第三轮）

用户诉求：`.sample` 会持续加入新图，需防止已分析过的图被重复分析；并明确**图片只在本地维护、不进 GitHub**。

### 关键发现
- 旧 `.gitignore` 第 9 行 `.sample` 整目录忽略，图片与 PROMPTS.md 被一刀切，文档也进不了 git。改为「图片按目录 + 扩展名双重忽略，文字产物入库」；父目录整行忽略时 `!` 无法还原子文件，故不能用 `.sample/`。
- 首批 17 张档名虽是 32 位 hex，但实测**并非内容哈希**（`0c67ffc8…jpg` 内容 md5 为 `593d5f2b…`）→ 去重键必须用内容 sha256 前 12 位，绝不能用档名。

### 目录规范（防重复三道保险：物理隔离 + hash 台账 + 扫描脚本）
- `.sample/inbox/` 唯一投放口（只留 `.gitkeep`）；`batches/<YYYY-MM-DD-主題>/{PROMPTS.md, images/}` 归档；根目录 `README.md`（SOP）、`INDEX.md`（唯一真相源台账）。
- 首批迁移：`.sample/anime/` → `.sample/batches/2026-11-22-anime/`，17 张图移入 `images/`。
- 状态机 `pending → prompted → landed → verified`，区分「分析过」与「已加进 APP」；首批 17 张全标 `verified`（已并入 general v2.1）。
- PROMPT 保存规范：**一批一份** PROMPTS.md（不拆单图档），固定五节，双识别（档名 + sha12），逐图序号回写 INDEX.md 的 PROMPT 锚点。
- 图片排除策略 + 「若想整个 .sample 只留本地」的一行开关，写进 `.sample/README.md`；工作流要点另沉淀到根目录 `STYLE-JSON.md` §8，不依赖 .sample 是否入库。

### 工具与文档
- 新建 `scripts/scan-samples.mjs` + `npm run samples:status`：遍历全 .sample 算 sha12、比对台账、报告 🆕未登记／✅已登记／⚠️内容重复／📦待归档；支持 `--verbose`／`--json`／`--register <批次>`。
